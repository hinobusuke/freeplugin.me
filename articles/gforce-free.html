GForce「Axxess」「M-Tron Select 2」が12月1日まで無料配布中

シンセメーカーの GForce Software が、シンセ「Axxess」と、メロトロン系音源「M-Tron」シリーズのセレクト版「M-Tron Select 2」を期間限定で無料配布しています。期間内に公式サイトで $0 チェックアウトすれば、恒久ライセンスとして自分のものになります。

対応形式は VST / VST3 / AU / AAX / スタンドアロン。入手は公式サイトから（要アカウント）。期限は 2026年12月1日 までです。詳細はトップページのデータベースから公式ページへどうぞ。
